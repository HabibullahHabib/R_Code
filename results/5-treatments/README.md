# Completed five-treatment simulation

The original run attempted **100,000 jobs**, with 10,000 replicates for each of two scenarios and five missing-rate settings and 40 imputations. Successful jobs: **100000**. Failed jobs: **0**. See completion_summary.csv and warning/error logs for actual counts and conditions. Original statistical settings and seeds were preserved; only computational worker allocation changed.

- [Full PDF report](simulation_report.pdf), [tables](main_tables.pdf), and [plots](simulation_plots.pdf).
- Table 2 coverage: [shrinkage](table2_shrink.csv), [non-shrinkage](table2_nonshrink.csv).
- Table 3 length/expansion: [shrinkage](table3_shrink.csv), [non-shrinkage](table3_nonshrink.csv).
- [Coverage summary](coverage_summary.csv), [length summary](length_summary.csv), and [joint coverage](joint_coverage_summary.csv).

The ZIP contains the original R script and console output. Supplementary plots were generated from results. Large raw per-replicate CSVs remain saved separately in the cloud environment and are excluded from this repository and ZIP. The full summary CSVs and four primary tables are included.
